﻿﻿# mouseBoys - Приложение для настройки беспроводной мышки

WPF приложение для настройки кастомной беспроводной мышки через радиоканал NRF24L01.

## Архитектура системы

```
[ПК] <--USB/Serial--> [Донгл: Arduino Nano + NRF24L01] <--Радиоканал--> [Мышка: MCU + NRF24L01]
```

## Функции приложения

### Курсор
- Инверсия осей X и Y
- Настройка чувствительности сенсора

### Подсветка
- Регулировка яркости (0-100%)
- Два режима: градиент или моноцвет
- Выбор цвета в формате RGB (R.G.B)
- Настройка скорости градиента

### Клавиши
- Настройка биндов для 9 кнопок (M1-M9)
- Возможность смены пароля доступа

## Протокол связи

### Команды от ПК к мышке:

| Команда | Описание |
|---------|----------|
| `GET_PASSWORD` | Запрос пароля для авторизации |
| `AUTH:пароль` | Авторизация с паролем |
| `GET_SETTINGS` | Запрос текущих настроек |
| `SET_SETTINGS:данные` | Установка настроек (требует авторизации) |
| `SET_PASSWORD:пароль` | Смена пароля (требует авторизации) |
| `PING` | Проверка связи |
| `PONG` | Ответ на пинг |

### Ответы от мышки:

| Ответ | Описание |
|-------|----------|
| `STORED_PASSWORD:пароль` | Пароль для проверки авторизации |
| `NO_PASSWORD` | На мышке не установлен пароль |
| `AUTH_OK` | Авторизация успешна |
| `AUTH_FAILED` | Неверный пароль |
| `SETTINGS:данные` | Текущие настройки |
| `OK` | Успешное сохранение |
| `ERROR` | Ошибка |
| `ERROR:NOT_AUTHENTICATED` | Требуется авторизация |
| `PASSWORD_CHANGED` | Пароль изменён |
| `PING` | Запрос связи |
| `PONG` | Ответ на пинг |

### Формат данных настроек:
```
invertX,invertY,sensitivity,brightness,isGradient,R.G.B,gradientSpeed,bind1|bind2|...|bind9
```

## Подключение NRF24L01 к Arduino Nano

| NRF24L01 | Arduino Nano |
|----------|--------------|
| VCC      | 3.3V         |
| GND      | GND          |
| CE       | D9           |
| CSN      | D10          |
| SCK      | D13          |
| MOSI     | D11          |
| MISO     | D12          |

⚠️ **Важно:** NRF24L01 питается от 3.3V, не подключайте к 5V!

## Arduino скетчи

В папке `Arduino/` находятся примеры скетчей:
- `dongle_nrf24l01.ino` - для донгла (Arduino Nano)
- `mouse_nrf24l01.ino` - для мышки (пример)

### Необходимые библиотеки Arduino:
- RF24 by TMRh20

Установка через Arduino IDE:
1. Sketch → Include Library → Manage Libraries
2. Поиск "RF24"
3. Установить "RF24 by TMRh20"

## Использование

1. Подключите донгл к USB порту ПК
2. Запустите приложение
3. Выберите COM-порт в выпадающем списке
4. **При подключении программа запросит пароль** (по умолчанию: `1234`)
5. После успешной авторизации настройки автоматически загрузятся с мышки
6. Измените нужные параметры
7. Нажмите "Сохранить" для записи на мышку
8. Нажмите "Сбросить" для загрузки текущих настроек с мышки

### Авторизация

При подключении к мышке программа запрашивает пароль:
- Пароль по умолчанию: **1234**
- Без правильного пароля невозможно изменять или просматривать настройки
- Для смены пароля используйте кнопку "Изменить пароль" в разделе "Клавиши"
- Пароль сохраняется в EEPROM мышки

## Логирование

Приложение включает полноценную систему логирования для отслеживания всех операций:

- **Подключение/отключение** от COM-портов
- **Отправленные команды** (TX) со стрелкой →
- **Полученные ответы** (RX) со стрелкой ←
- **Ошибки и предупреждения** с соответствующими метками
- **Таймстампы** с точностью до миллисекунд

### Уровни логов:
- `INFO` - общая информация
- `SUCCESS` - успешные операции (✓)
- `WARNING` - предупреждения
- `ERROR` - ошибки (✗)
- `TX` - отправка данных (→)
- `RX` - приём данных (←)

Лог отображается в раскрывающейся секции внизу окна. Максимум 500 строк с автоматической очисткой старых записей.

Подробнее см. [LOGGING.md](LOGGING.md)
