# Решение проблемы "Access to the path 'COMx' is denied"

## Проблема

При подключении к COM-порту возникает ошибка:
```
Access to the path 'COM10' is denied
```

## Причины

Эта ошибка возникает в следующих случаях:

### 1. Порт уже используется другим приложением
- **Arduino IDE** (Serial Monitor открыт)
- **PuTTY** или другие терминалы
- **Другой экземпляр mouseBoys**
- **Device Manager** (просмотр свойств порта)
- **Системные службы мониторинга**

### 2. Недостаточно прав доступа
- Программа запущена без прав администратора
- Ограничения групповых политик Windows

### 3. Драйвер устройства
- Драйвер работает некорректно
- Драйвер не установлен
- Конфликт драйверов

## Как исправить

### Метод 1: Закрыть другие программы (РЕКОМЕНДУЕТСЯ)

1. **Закройте Arduino IDE**
   - Особенно если открыт Serial Monitor (Ctrl+Shift+M)
   
2. **Закройте терминалы**
   - PuTTY
   - TeraTerm
   - Встроенный терминал Windows
   
3. **Проверьте диспетчер задач**
   - Найдите процессы, использующие COM-порт
   - Завершите их

4. **Переподключите устройство**
   - Отключите USB кабель
   - Подождите 3 секунды
   - Подключите снова

### Метод 2: Запустить от имени администратора

1. Закройте приложение mouseBoys
2. Найдите `mouseBoys.exe`
3. ПКМ → "Запуск от имени администратора"

### Метод 3: Проверить драйверы

1. Откройте **Диспетчер устройств** (Win+X → Device Manager)
2. Найдите **Порты (COM и LPT)**
3. Найдите ваш Arduino/USB-Serial порт
4. ПКМ → **Обновить драйвер**
5. Или переустановите драйвер CH340/CP2102/FTDI

### Метод 4: Использовать PowerShell для поиска процесса

```powershell
# Показать процессы, использующие COM-порты
Get-WmiObject Win32_SerialPort | Select-Object Name, DeviceID

# Найти процессы, блокирующие файлы (требует Handle.exe от Sysinternals)
handle.exe COM10
```

## Частые вопросы

### Q: Почему порт занят, если ничего не запущено?
**A:** Проверьте:
- Фоновые службы Windows
- Антивирус (может сканировать USB-устройства)
- Программы мониторинга (Process Monitor и т.д.)

### Q: Помогает ли перезагрузка?
**A:** Да, перезагрузка освобождает все порты и сбрасывает драйверы.

### Q: Можно ли использовать два приложения с одним портом?
**A:** Нет, COM-порт может использовать только одно приложение одновременно.

### Q: Что делать, если ничего не помогает?
**A:** 
1. Переподключите устройство к другому USB порту
2. Проверьте кабель
3. Переустановите драйверы
4. Проверьте устройство на другом компьютере
